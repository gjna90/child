# 내 PC에서 유보통합포털 요강 자동 수집하기

유보통합포털(enter.childinfo.go.kr)은 해외 접속을 막습니다. 그래서 클라우드 작업 환경에서는 열 수 없습니다. **한국에 있는 내 PC**에서 이 스크립트를 돌리면 포털의 모집요강을 모아 저장소에 올립니다. 그러면 월·목 클라우드 정기 수집이 읽어서 앱에 반영합니다.

```
내 PC (한국) ── 실제 브라우저로 요강 조회 ──▶ data/portal_inbox/<날짜>/ ──git push──▶ 저장소
                                                                         │
클라우드 정기 수집(월·목 08:43) ◀──────────────────────────────────────────┘
  → 첨부 글자 풀기(inbox-extract) → 요강 정리(data/admissions) → 앱 다시 게시
```

## 1. 처음 한 번 준비 (Windows 기준, 약 15분)

1. **Node.js** 설치: https://nodejs.org 에서 LTS 버전을 받아 기본값으로 설치합니다.
2. **Git** 설치: https://git-scm.com 에서 받아 기본값으로 설치합니다.
3. 저장소 받기: 시작 메뉴에서 **Git Bash**(또는 명령 프롬프트)를 열고 아래를 입력합니다.
   ```
   git clone https://github.com/gjna90/child.git
   cd child
   git checkout stage1-api-extras
   ```
   GitHub 로그인 창이 뜨면 로그인합니다. 올리기(push)에도 이 로그인이 쓰입니다.
4. 브라우저 도구 설치 (한 번만):
   ```
   npm i --no-save playwright
   npx playwright install chromium
   ```

> Claude Desktop 앱을 쓰신다면 앱에서 이 폴더를 열고 "docs/10 대로 포털 수집 준비해 줘"라고 해도 됩니다.

## 2. 첫 실행은 '학습 모드'로 (권장)

제가 클라우드에서 포털 화면을 본 적이 없어서, 자동 찾기가 처음부터 맞지 않을 수 있습니다. 첫 실행은 학습 모드로 해 주세요.

```
node scripts/portal/collect-portal.js --learn --push
```

1. 브라우저 창이 열립니다. 평소처럼 **유치원입학 → 모집요강 조회**로 가서 배방·탕정 유치원 요강을 하나씩 엽니다.
   대상은 시작할 때 화면에 나옵니다. 기본은 요강을 아직 못 읽은 곳입니다.
2. 요강 화면이면 **자동으로 저장**됩니다. 저장되지 않으면 화면 오른쪽 아래 초록 **[이 화면 저장]** 버튼을 누르세요. 첨부(PDF·HWP)도 함께 받습니다.
3. 다 보셨으면 **창을 닫으세요**. 그러면 저장소에 올라갑니다(`--push`).
4. 학습 모드는 거쳐 간 화면의 구조를 `data/raw/portal/probe/`에 남깁니다. 저장소에는 올라가지 않습니다.
   - 이 폴더를 압축해 보내 주시면, 제가 자동 모드가 정확히 찾도록 고치겠습니다.
   - 화면 캡처 몇 장도 괜찮습니다.

## 3. 자동 실행

```
node scripts/portal/collect-portal.js --push          # 요강 미확인 유치원만
node scripts/portal/collect-portal.js --all --push    # 배방·탕정 21곳 전부
```

- 브라우저 창이 열리고 혼자 '모집요강' 메뉴 → 기관명 검색 → 요강 열기 → 저장을 합니다.
- 못 찾은 곳은 끝에 목록으로 알려 줍니다. 그곳은 학습 모드로 한 번 저장해 주세요.

### 정해진 시간에 자동으로 (Windows 작업 스케줄러)

1. 시작 메뉴 → **작업 스케줄러** → 오른쪽 **기본 작업 만들기**
2. 이름: `유치원 요강 수집` → 트리거: **매주** 월·목, 시간은 **07:30**(클라우드 수집 08:43보다 먼저)
3. 동작: **프로그램 시작** → 프로그램: `child\scripts\portal\run-portal.cmd`의 전체 경로 → 마침
4. PC가 켜져 있고 로그인된 상태여야 실행됩니다. 브라우저 창이 잠깐 열렸다 닫힙니다.

Mac은 `scripts/portal/run-portal.sh`를 cron이나 자동화(Automator)로 실행합니다.

## 4. 지키는 것

- **실제 브라우저 창**으로, 화면마다 3~6초 쉬며 우리 지역 대상만 엽니다. 주 1~2회만 실행합니다.
- 로그인·지원서·개인정보 화면은 열지 않고, 공개된 '모집요강 조회'만 읽습니다.
- 보안 확인(자동입력 방지 등) 화면이 나오면 **우회하지 않습니다.** 직접 통과하시거나, 그날은 멈춥니다.
- 받은 요강은 공개 문서이며, 정리할 때는 원문에서 확인한 값만 앱에 넣습니다(기존 규칙과 같음).

## 5. 클라우드 쪽 처리

- `node scripts/portal/inbox-extract.js`
  - 받은 첨부(PDF·HWP·HWPX)를 글자로 풀어 같은 폴더에 `.txt`로 저장합니다.
  - 아직 앱에 정리되지 않은 곳을 목록으로 알려 줍니다.
- 정기 수집 루틴이 이 목록을 읽고 `data/admissions/2027_kinder.js`에 옮긴 뒤 앱을 다시 게시합니다.

## 6. 문제가 생기면

| 증상 | 할 일 |
|---|---|
| `playwright가 없습니다` | 1-4단계 두 줄 실행 |
| 창이 열리자마자 닫히고 "모집요강 메뉴를 찾지 못함" | `--learn` 으로 실행, probe 폴더 보내 주기 |
| `git 올리기 실패` | Git Bash에서 `git push origin HEAD:stage1-api-extras` 직접 실행(로그인 창이 뜨면 로그인) |
| 포털이 점검 중·접속 오류 | 다음 예약 시간에 다시 실행됨 — 그대로 두기 |
