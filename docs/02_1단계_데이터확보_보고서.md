# 1단계 데이터 확보 검증 보고서

조회일: 2026-10-26 (Asia/Seoul) · 모집 학년도: 2027 · 지역: 아산시 배방읍·탕정면

## 결론 먼저

- **공식 명부는 아직 확보하지 못했다.** 이 작업 환경의 인터넷이 한국 공식 사이트(유치원알리미·아이사랑·어린이집정보공개포털·공공데이터포털·아산시 등)를 막고 있다.
- 웹 검색 요약으로 **후보 29곳**을 찾아 따로 기록했다(`data/candidates/2026-10-26_검색후보.json`). 원문을 열지 못했으므로 모두 '검색 요약만 확인' 상태이며, **"모든 기관 조사 완료"가 아니다.**
- 공식 자료가 들어오면 바로 정리·분류하는 코드(연령반 판별, 가정어린이집 제외, 중복·동명 기관 점검, 미확인 보존)를 만들고 테스트 21개를 통과했다.

- 2027학년도: 2023년생 = 만3세반 = 옛 표기 '5세반' / 2022년생 = 만4세반 / 2021년생 = 만5세반

## 6. 남은 일과 막힌 이유

1. **네트워크 허용** (사용자 설정 필요) → 그러면 공식 사이트 원문·API를 직접 읽음
   - 단, 공식 사이트가 해외 접속을 막을 수도 있음. 그 경우 사용자가 PC에서 파일을 내려받아 올려주는 방식으로 대체
2. **인증키 발급**: 유치원알리미 Open API, 어린이집정보공개포털 Open API
3. 키가 들어오면: `npm run collect` → 공식 명부로 기관 수 집계·누락 대조 → 후보 29곳과 비교
4. 3~5곳 모집요강·설명회: 기관 홈페이지·유보통합포털 공지 원문 확인 (2026년 게시 2027학년도 공지와 과거 공지 구분)

## 8. 3차 수집 결과 (2026-10-26, 유치원알리미 API 인증키)

### 결론 먼저
- 인증키로 유치원알리미 Open API에 접속됨. 아산시 코드(시도 44 · 시군구 44200)가 맞음을 응답으로 확인.
- 배방·탕정 유치원은 **그대로 21곳**. 21곳 모두에 키로만 받는 5개 항목(방과후 운영시간 등)을 붙임.
- 어린이집은 여전히 미수집 → **"모든 기관 조사 완료" 아님.**

### 아산시 코드 확인
| 자료 | 아산시 건수 | 비고 |
|---|---|---|
| 일괄자료 (2026년 2차 공시, 키 불필요) | 60곳 | |
| 기본현황 API (basicInfo2) | 67건 | 60곳은 최신 공시(20262), 7곳은 예전 공시(20232~20252)에만 남은 기관 |

- 예전 공시에만 남은 7곳(염티·도고온천·온양신정·송곡·온양초사·용화·쌍룡 초등학교 병설)은 모두 배방·탕정 밖. 휴원·폐원 여부는 확인하지 않았고, 코드에서 '최신 공시에 없음 — 확인 필요'로 표시함(운영 중으로 단정하지 않음).

### 같은 유치원이 두 번 잡히던 문제 — 고침
- API 자료는 `kinder:<유치원코드>`, 일괄자료는 코드가 없어 `kinder:<이름>@<주소>` 로 식별돼 같은 유치원이 두 번 들어가던 문제.
- 이름+주소(띄어쓰기만 무시)가 같고 한쪽만 코드가 있으면 하나로 합치고 유치원코드를 붙임. 코드가 서로 다른 두 기관은 합치지 않음(같은 이름 경고로 처리).
- 합칠 때 한쪽이 비어 있으면 다른 쪽 값으로 채우고, 둘 다 값이 있는데 다르면 앞의 값을 두고 다른 값을 변경 이력에 남김(같은 공시차수면 '출처 간 불일치' 표시).
- 결과: 60곳 합침, 배방·탕정 21곳 모두 유치원코드 확보, 출처 간 불일치 0건. 일괄자료에 없던 **운영시간**이 API에서 채워짐.
- 코드: `src/importers/roster.js` (`mergeAcrossSources`, `markStaleRounds`), 테스트: `test/merge.test.js`

### 키로 받은 항목 (항목 뜻은 유치원알리미 Open API 안내 페이지의 출력 항목 설명 기준)
| API 항목 | 공시차수 | 붙인 내용 |
|---|---|---|
| afterSchoolPresent (방과후 과정 편성·운영) | 2026년 1차 | 운영시간, 독립편성·오후재편성 학급수와 참여원아수, 담당 인원(정규·기간제·전담·보육·기타) |
| classArea (교실 면적) | 2026년 1차 | 교실 수, 교실·체육장·보건위생·조리급식·기타 공간 면적 |
| building (건물) | 2026년 1차 | 건축년도, 층수, 건물전용면적, 대지총면적 |
| lessonDay (수업일수) | 2026년 1차 | 연령별·혼합·특수·방과후 수업일수, 법정일수 이하 여부 |
| safetyEdu (안전점검·안전교육) | 2026년 2차 | 놀이시설 안전검사(대상·일자·결과), CCTV 수(건물 안/밖), 소방·가스·전기 점검 |

- 빈칸이나 모양을 알 수 없는 값은 미확인(null). 0으로 채우지 않음. 공시에 0으로 적힌 값은 공시값 0으로 둠.
- 응답 원문은 `data/raw/api_kinder/` 에 저장(인증키 문자열 제거, 공개 저장소에는 올리지 않음).

- **운영시간**: 공시 운영시간은 방과후까지 포함한 하루 전체 시간(기본현황 운영시간 = 방과후 운영시간, 21곳 모두 같음). 정규과정 시작·끝 시간은 공시에 없음.
- 19시 이후까지 운영(공시값): 삼성샛별 08:00~19:00, 아산세교 07:40~19:40, 일심 07:30~19:30, 자연 08:30~19:00, 하나 07:30~19:30, 한들물빛 08:00~19:30.
- 혼합반만 있는 병설 2곳(금곡·연화)은 16:30까지로 공시됨.
- **체육장 면적**: 공시 항목명이 '체육장'이고 실내·실외 구분이 없음. 21곳 중 11곳이 0㎡로 공시됨(빈칸이 아니라 0). 병설은 초등학교 운동장을, 단설은 인근 시설을 쓰는지 기관 확인 필요. '놀이터 없음'으로 해석하지 않음.
- 병설은 건물·대지 공시값이 초등학교 전체 기준일 수 있음.
- 방과후 담당 인원은 기관 전체의 직위별 공시값. 반별 배치로 쓰지 않고, 정규 교직원 수와 더하지 않음.
