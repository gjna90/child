# 1단계 데이터 확보 검증 보고서

조회일: 2026-10-26 (Asia/Seoul) · 모집 학년도: 2027 · 지역: 아산시 배방읍·탕정면

## 결론 먼저

- **공식 명부는 아직 확보하지 못했다.** 이 작업 환경의 인터넷이 한국 공식 사이트(유치원알리미·아이사랑·어린이집정보공개포털·공공데이터포털·아산시 등)를 막고 있다.
- 웹 검색 요약으로 **후보 29곳**을 찾아 따로 기록했다(`data/candidates/2026-10-26_검색후보.json`). 원문을 열지 못했으므로 모두 '검색 요약만 확인' 상태이며, **"모든 기관 조사 완료"가 아니다.**
- 공식 자료가 들어오면 바로 정리·분류하는 코드(연령반 판별, 가정어린이집 제외, 중복·동명 기관 점검, 미확인 보존)를 만들고 테스트 21개를 통과했다.

## 3. 후보 집계 (검색 요약 기준, 공식 명부 아님)

| 구분 | 배방읍 | 탕정면 | 지역 확인 필요 | 계 |
|---|---|---|---|---|
| 유치원 | 11 | 6 | 1 | 18 |
| 어린이집 | 4 | 5 | 2 | 11 |
| **계** | **15** | **11** | **3** | **29** |

- 제외(재확인 필요): 탕정엘리프어린이집 — 만0~2세만 운영으로 표기, 유아반(5세 이상반) 없음
- 판단 보류: 삼성전자온양·하버드·큰숲어린이집 — 직장·민간·가정이 섞여 표기됨
- 확인 필요 예시: 배방유치원(주소에 읍·면 없음), 탕정미래초병설(‘미운영 이전’ 표기), 탕정삼성어린이집(직장 여부 미확인)
- 출처별(한 기관이 여러 출처에 중복 포함): 유치원알리미 발췌 2곳, 아산시 과거 목록 7곳, 아산시 시간제 어린이집 안내 1곳, 제3자 정리 사이트 24곳, 위키백과 1곳

## 5. 연령반 해석 기준 (검증 완료)

- 2027학년도: 2023년생 = 만3세반 = 옛 표기 '5세반' / 2022년생 = 만4세반 / 2021년생 = 만5세반
- '5세반'만 적힌 경우 → 2023년생(세는나이) 또는 2021년생(만 나이) 두 해석 → '대상 여부 확인 필요'
- 같은 기관에 6·7세반이 있으면 세는나이 표기로 추정(여전히 출생연도 확인 권장)
- 2027 모집 대상(타 시·도 기사): 2021.1.1~2023.12.31생 — 충남 요강으로 재확인 필요

## 6. 남은 일과 막힌 이유

1. **네트워크 허용** (사용자 설정 필요) → 그러면 공식 사이트 원문·API를 직접 읽음
   - 단, 공식 사이트가 해외 접속을 막을 수도 있음. 그 경우 사용자가 PC에서 파일을 내려받아 올려주는 방식으로 대체
2. **인증키 발급**: 유치원알리미 Open API, 어린이집정보공개포털 Open API
3. 키가 들어오면: `npm run collect` → 공식 명부로 기관 수 집계·누락 대조 → 후보 29곳과 비교
4. 3~5곳 모집요강·설명회: 기관 홈페이지·유보통합포털 공지 원문 확인 (2026년 게시 2027학년도 공지와 과거 공지 구분)

- 출처: 유치원알리미 2026년 2차 공시 일괄자료 (충남 404곳) — 일반현황·교직원·근속·급식·통학차량
