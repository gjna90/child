# 4단계 추천 규칙 — 맞춤 추천

계산 코드: `src/lib/recommend.js` (테스트: `test/recommend.test.js`). 화면은 같은 코드를 그대로 끼워 넣어 씁니다(`scripts/build-app.js`).
AI는 계산에 쓰지 않습니다. 화면 문구는 "선택하신 기준에 따른 비교 지표"이며 적합도·합격 가능성·적응 성공률이 아닙니다. 인기·후기 수·홍보량은 쓰지 않습니다.

## 1. 누구 기준

- **아이별**: '우리 아이 성향·생활 알아보기' 탭에서 추가한 아이마다 따로 계산합니다(출생연도에 따라 반 여부·반 규모가 달라짐). 아이가 없으면 헤더의 출생연도로 계산합니다.
- **가족 전체**(아이 2명 이상): 모든 아이가 필수 조건을 통과한 곳만 '추천 후보'. 한 아이라도 불충족이면 '조건 불충족', 미확인이 있으면 '추가 확인 후보'.
  - 비교 지표·확인 정도는 **아이들 중 낮은 값**으로 정렬합니다. 한 아이의 약점이 다른 아이의 장점에 가려지지 않게 하기 위해서입니다. 아이별 값·우려는 카드에 나란히 보여 줍니다.
  - 같은 반·다른 반은 정답으로 정하지 않습니다. 형제 동시 입학 가능 여부는 질문으로 확인합니다.

## 2. 필수 조건 (점수와 분리)

| 조건 | 충족 | 불충족 | 미확인 |
|---|---|---|---|
| 우리 아이 반 있음 | 2027 요강에 해당 출생연도 반 / 요강이 없으면 올해 공시에 해당 연령 반 | 요강·공시에 해당 반 없음 | 혼합반만 있음, 학원 |
| 18:30 이후 돌봄·운영 | 공시 운영시간·요강 돌봄 끝 시각 ≥ 18:30 | 그 전에 끝남 | 시각 미확인, 학원 |
| 통학버스 | 요강·공시에 운행 | 없음·미운행 | 미확인 |
| 출발지 반경 안 | 직선거리 ≤ 반경 | 반경 밖 | 출발지·좌표 없음 |
| 부모 부담금 없음 | 요강에 "부담금 없음·무상" | (불충족 판정 안 함) | 그 외 |
| 예산 이하 | 확인된 월 비용 ≤ 예산 | 초과 | 비용 미확인, 예산 미입력 |

불충족이 하나라도 있으면 다른 장점으로 메우지 않고 '조건 불충족' 묶음에 이유와 함께 둡니다.

## 3. 선호 기준 → 0~1 값

| 기준 | 값 | 미확인일 때 |
|---|---|---|
| 이동 — 직선거리 | 괜찮은 거리(기본 1km)=1, 최대 거리(기본 4km)=0, 사이 직선 | 출발지·좌표 없음 → 계산에서 뺌 |
| 이동 — 도보 시간 | 우리 아파트→기관 카카오 도보 경로: 괜찮은 시간(기본 10분)=1, 최대(기본 30분)=0. 직선 2.5km 넘어 경로를 계산하지 않은 곳은 **직선거리 ÷ 분당 67m를 최소 시간**으로 계산(걷는 거리는 직선보다 짧을 수 없음) | 아파트를 고르지 않음 → 뺌 |
| 이동 — 자동차 시간 | 카카오모빌리티 길찾기(조회 시점 교통): 괜찮은 시간(기본 5분)=1, 최대(기본 20분)=0. 통학버스 탑승 시간으로 쓰지 않음 | 아파트 미선택·7km 밖 → 뺌 |
| 돌봄 시간 | 끝나는 시각 ≥ 필요한 하원 시각 → 1, 아니면 0 | 시각 미확인 → 뺌 |
| 비용 | 부담금 없음=1. 예산 입력 시: 예산의 50% 이하=1, 예산=0.3, 사이 직선, 초과=0 | 금액 미확인·예산 미입력 → 뺌 |
| 해당 연령 반 규모 | 올해 공시 반당 원아수: 기준(기본 16명) 이하=1, 기준×1.5 이상=0 | 혼합반·해당 반 없음 → 뺌 (기관 전체 평균으로 대신하지 않음) |
| 통학 편의(버스) | 운행=1, 없음=0 | 미확인 → 뺌 |
| 자연·바깥놀이 | (빈도 확인된 곳 없음) | 모두 미확인 → 상담 질문 |
| 설문에서 고른 지원 | (기관 지원 정보 확인된 곳 없음) | 모두 미확인 → 상담 질문 |

비용 금액은 요강·홈페이지에 숫자로 적힌 경우만 씁니다(예: 일심 특성화비 월 4만 원). 영어유치원은 가장 긴 과정의 **등록 교습비**입니다.

## 4. 두 가지 정렬

### 여러 조건 종합
- 중요도: 매우 중요=3, 중요=2, 참고=1
- **비교 지표** = Σ(가중치×값) ÷ Σ(확인된 기준의 가중치) × 100
- **정보 확인 정도** = Σ(확인된 기준의 가중치) ÷ Σ(전체 가중치) — 지표와 따로 표시
- 확인 정도 50% 미만은 위로 올리지 않고 '정보 부족' 묶음으로 → 한 항목만 확인된 곳이 1위가 되는 것을 막음
- 동점: 확인 정도 높은 순 → 직선거리 가까운 순 → 이름순

### 우선순위대로
- 1번 기준으로 묶음(거리는 0~1 값을 6단계, 나머지는 10단계) → 같은 묶음 안에서 2번 → 3번 …
- 그 기준이 미확인이면 그 단계에서 순위를 매기지 않고 뒤로 보냄
- 마지막 동점: 직선거리 → 이름

## 5. 카드에 보여 주는 것

기관명·유형·지역, (종합일 때) 비교 지표와 확인 정도, 아이별 반 여부, 기준별 값(좋음·보통·아쉬움·미확인 색), **추천 이유**(값 0.7 이상이면서 중요 이상인 기준), **우려·확인할 점**(값 0.4 미만, 필수 조건 미확인), **상담 질문**(미확인 기준), 출처·기준일.

## 6. 상담 기록 반영 (5단계)

- '전화·상담 질문지' 탭의 **상담 결과 기록**(사용자 입력, 이 기기에만 저장)은 **공식 자료에 값이 없을 때만** 계산에 들어가고 "(상담 기록 날짜)"로 표시합니다. 공식 자료와 다르면 둘 다 보여 줍니다(예: 비용). 자동 수집이 상담 기록을 지우지 않고, 상담 기록이 공식 자료를 바꾸지 않습니다.
- 반영 항목: 돌봄 끝나는 시각(돌봄 시간·18:30 조건), 한 달 실제 비용(비용·예산 조건), 우리 아이 반 예상 인원(반 규모 — 공시보다 상담값을 우선: 2027 반 편성은 공시에 없으므로), 우리 집 쪽 버스(통학 편의·버스 조건)
- 바깥놀이 빈도: 주 3회 이상=1, 주 1~2회=0.6, 월 1~3회=0.3, 거의 없음=0
- 설문에서 고른 지원: 기관 답 있음=1, 일부=0.5, 없음=0의 평균(답한 것만). 고른 지원이 없거나 답이 없으면 미확인
- 내 진행 상태(관심·설명회 신청·지원·선발·대기·등록 등)는 직접 적는 메모이며 추천 순위에 쓰지 않습니다. 카드와 달력에 표시만 합니다.
