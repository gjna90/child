## 2. 저장과 권한

| 무엇 | 어디에 | 누가 볼 수 있나 |
|---|---|---|
| 유치원 공개정보(공시·요강·영어유치원 등록 자료) | 화면 파일 안 | 페이지를 열 수 있는 모든 사람(읽기 전용) |
| 개인 기록(아이 설문·상담 기록·메모·희망 순서·출발지·직접 넣은 일정·보관한 공지·설정) | 각자의 claude.ai 계정 비공개 공간 `data/users/<본인>/state` | **본인만** — 페이지 주인도 다른 사람 것을 못 봄 |
| 로그인 안 한 화면 | 그 기기 브라우저 | 그 기기만 |

- 권한 규칙(페이지에 선언, 플랫폼이 강제): 공용 영역은 모두 읽기·주인만 쓰기, `data/users/{self}`는 사용자 본인만 읽고 씀.
- 처음 계정 저장이 켜지면, 그 기기에 있던 기록을 한 번 계정으로 옮깁니다. 이후에는 바뀐 뒤 1.5초 쉬면 한 번 저장합니다(바뀐 것이 없으면 쓰지 않음).
- 같은 계정으로 휴대폰·PC를 동시에 쓰면 나중에 저장한 쪽이 남습니다(열 때 계정 기록을 불러옴).
- 정확한 주소·생년월일·건강정보는 필수로 받지 않습니다(별명·출생연도만). 출발지는 지도에서 찍은 대략 위치이며 외부 서비스로 보내지 않습니다.

## 2-0. 관리자가 자동으로 보는 기록 (2026-10-30, 사용자 결정: 3번 '섞기')

| 관리자가 자동으로 봄 → `visible/<id>` (주인만 읽음) | 본인만 봄 → `data/users/<id>/state` |
|---|---|
| 지원할 3곳, 비교함, 꼭 필요한 조건, 추천 설정, 아이 출생연도 | 아이 설문·생활 정보, 상담 기록·진행 상태, 메모, 출발지, 가족 조건(다자녀·저소득·장애·다문화 등), 직접 넣은 일정·보관한 공지 |

- 개인 공간에는 전체가 그대로 저장되고, 왼쪽 항목만 사본으로 `visible/<id>`에 함께 저장됩니다(바뀔 때만).
- 화면 위쪽에 처음 한 번 안내가 뜨고('확인'을 누르면 숨김), 저장 상태 줄과 '내 기록 관리'에도 같은 내용이 적혀 있습니다.
- 권한 규칙: `{ path: "visible", read: "owner", write: "owner" }`, `{ path: "visible/{self}", read: "interact", write: "interact" }`.
- '내 기록 모두 지우기'는 이 사본도 지웁니다.

## 2-1. 관리자에게 보내기 (2026-10-30)

| 무엇 | 어디에 | 누가 볼 수 있나 |
|---|---|---|
| 사용자가 '내 기록 관리 > 관리자에게 보내기'에서 고른 항목의 사본 + 남긴 말 | `inbox/<보낸 사람>` | **페이지 주인**과 보낸 본인만 (보낸 사람은 언제든 지움) |

- 권한 규칙: `{ path: "inbox", read: "owner", write: "owner" }`, `{ path: "inbox/{self}", write: "interact" }`. 개인 기록 공간(`data/users/<id>`)은 플랫폼 규칙상 주인도 못 보므로, 자동으로 복사하지 않고 사용자가 고른 것만 보냅니다.
- 주인은 같은 탭 아래 '관리자: 받은 기록'에서 보낸 사람 이름(claude.ai 프로필), 시각, 요약, 메시지, 원본을 보고 전체를 파일로 받을 수 있습니다.
- 아이 정보가 들어 있으므로 받은 기록을 다른 곳에 옮기거나 공유하지 않습니다.

## 3. 다른 학부모와 함께 쓰기

1. 페이지 오른쪽 위 **공유(Share)** 메뉴를 엽니다.
2. 함께 쓸 사람을 추가할 때 권한을 **참여자(Contributor)** 이상으로 고릅니다.
   - '보기(Viewer)'로 공유하면 그 사람은 화면을 볼 수는 있지만 자기 기록을 계정에 저장할 수 없습니다(그 기기에만 저장).
3. 각자 기록은 서로 보이지 않습니다. 비교표를 보여 주고 싶으면 화면을 캡처해 보내세요(개인 기록은 기본 포함하지 않음).

## 6. 아직 안 되는 것 (알려진 제한)

- **어린이집**: 웹사이트(https)는 해외 접속 차단이지만 **Open API 주소(http://api.childcare.go.kr/…)는 이 환경에서 응답함**(2026-10-27 확인). 사용자가 '어린이집별 기본정보 조회'·'전국 어린이집 정보 조회'를 신청해 승인 대기 중. 키가 오면 환경 비밀값 `CHILDCARE_API_KEY`로 넣고 `npm run collect`. 주의: http라 인증키가 암호화되지 않은 채 전송됨(포털이 https를 해외에 막아 대안 없음 — 조회 전용 키).
- **도보·자동차 이동시간**: ✅ 카카오 키(`KAKAO_REST_API_KEY`) 연결 완료(2026-10-27). 화면 페이지는 보안 규칙상 카카오에 직접 연결할 수 없어, **배방·탕정 아파트 단지 86곳 → 기관**의 도보(직선 2.5km 안)·자동차(7km 안) 경로를 미리 계산해 넣음. 아파트 목록에 없는 곳은 지도를 눌러 직선거리만 사용. 집 위치는 카카오로 보내지 않음.
  - 다시 계산: `node scripts/kakao-routes.js apartments` → `geocode` → `routes` (도보 무료 하루 1,000건 — 한도에 걸리면 다음 날 `routes`를 다시 실행하면 이어서 계산) → `node scripts/build-app.js`
  - 무료 쿼터: 카카오맵 API를 처음 켠 앱에만 적용. 신규 경로 API(도보 등)는 하루 1,000건, 초과 시 건당 10원(비즈월렛 연결해야 유료 사용 가능 — 연결하지 않으면 과금 없이 멈춤).
- **유보통합포털·교육청·아산시 공지**: 접속 차단 → 기관 홈페이지 원문으로 대신함.
- **사진 속 글자 읽기**(공지 캡처): 미지원 — 글자를 복사해 붙여 넣기.
- **claude.ai 계정이 없는 사람에게 공개 배포**: 지금 구조는 claude.ai 로그인이 필요. 누구나 쓰는 공개 웹사이트로 내려면 Vercel(호스팅)·Supabase(로그인·DB·행 단위 권한) 계정이 필요하며, 이 경우 개인 기록 테이블마다 `user_id`와 RLS를 두는 설계(docs/01 2장)를 그대로 옮깁니다.

## 6-1. 지도

- 바탕 지도는 OpenStreetMap 자료(© OpenStreetMap contributors, ODbL)를 2026-10-29에 한 번 받아 줄여 넣은 것입니다(`data/geo/osm_basemap.json`, 약 235KB). 도로·철도·하천·공원·학교·역·이름 있는 단지가 들어 있습니다.
- 화면 페이지는 보안 규칙상 카카오·구글 지도 그림을 불러올 수 없습니다. 그래서 바탕을 직접 그리고, 상세보기의 **카카오맵에서 보기·길찾기** 버튼으로 진짜 카카오맵을 새 탭에 엽니다.
- 다시 만들기: OpenStreetMap API(`/api/0.6/map?bbox=`)로 배방·탕정을 20조각으로 받아 `data/raw/osm/`에 둔 뒤 `python3 -I scripts/osm-extract.py` → `node scripts/build-app.js`. 주 단위 갱신은 필요 없습니다(새 도로가 생겼을 때만).
