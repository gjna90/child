# 3단계 설문 규칙 — 우리 아이 성향·생활 알아보기

- 자체 설문 초안이며 표준화된 심리·발달 검사나 진단이 아닙니다. 기관을 고를 때 무엇을 확인할지 정리하는 참고 도구입니다.
- 아이마다 따로, 날짜별로 다시 작성합니다. 최근 2~4주 관찰 기준. 부모·교사 관찰을 따로 저장하고 다르면 "환경별 차이"로 나란히 보여 줍니다(어느 쪽이 맞다고 정하지 않음).
- 응답: 거의 없음 / 가끔 / 자주 / 대부분 / 관찰 기회 없음. **점수로 바꾸지 않습니다.**
  - "자주·대부분" → 그 문항의 해석을 결과에 넣음
  - "거의 없음·가끔" → 넣지 않음 (17번만 예외: 낮으면 "도움 요청을 어른이 먼저 살펴 줄 필요")
  - "관찰 기회 없음" → 중간값·낮은 값으로 처리하지 않고 "아직 관찰하지 못한 부분"에만 표시
- 지원 제안은 "잠정 제안"이며 부모가 중요한 것을 고릅니다(★). 기관 지원 정보는 대부분 미확인이라 맞는 곳이라고 추측하지 않고 질문지 질문으로 연결합니다.
- 성향 하나로 특정 교육 방식(숲·몬테소리 등)을 정답으로 정하지 않습니다. 부모의 바람과 아이의 실제 선호는 따로 적습니다.
- 저장 위치: 지금은 이 기기 브라우저(localStorage)에만. 서버로 보내지 않음. 계정 저장은 6단계.

## 지원 → 상담 질문

| 지원 | 상담 질문 |
|---|---|
| 적응 지원 | 처음 적응 기간에 단계적 등원이나 보호자 동반, 사전 방문이 가능한가요? |
| 활동 전환 안내 | 활동을 바꿀 때 미리 알려 주시나요? 하던 놀이를 마무리할 시간을 주시나요? |
| 움직임 기회 | 하루에 바깥놀이·신체활동 시간은 얼마나 되고, 앉아서 하는 활동 중 잠깐 움직이거나 쉴 수 있나요? |
| 자유놀이·선택 | 자유놀이 시간은 하루에 얼마나 되고, 아이가 놀이를 고르고 오래 이어 갈 수 있나요? |
| 조용한 휴식 공간 | 시끄럽거나 지칠 때 쉴 수 있는 조용한 공간이 있나요? 참여 방식을 조정해 주시나요? |
| 재료·촉감 배려 | 싫어하는 촉감·재료 활동은 다른 활동을 고를 수 있나요? |
| 친구 사귀기 도움 | 소그룹 활동이 있나요? 처음에 친구와 이어지도록 도와주시나요? |
| 도움 요청 살피기 | 아이가 불편을 말로 잘 표현하지 못할 때 선생님이 어떻게 알아채고 도와주시나요? |
| 갈등·감정 지원 | 친구와 의견이 부딪치면 어떻게 중재하고, 감정 표현을 어떻게 도와주시나요? |
| 재도전 지원 | 뜻대로 안 돼서 그만두려 할 때 어떻게 격려하시나요? 결과보다 과정을 말해 주시나요? |
| 발표 부담 조정 | 발표·공연처럼 여러 사람 앞에서 하는 활동은 참여 방식을 조정해 줄 수 있나요? |
| 직접 해보는 활동 | 설명 위주보다 직접 보고 해보는 활동이 많은 편인가요? |

## 생활 질문 → 상담 질문

- 낮잠 → 낮잠 시간과 안 자는 아이의 활동
- 식사 → 식사 도움·편식 지도
- 배변·옷·낯선 화장실 → 도움 범위와 화장실 적응
- 차·버스 반응 → 가장 긴 탑승 시간과 우리 집 쪽 탑승 시간
- 의사소통·건강 지원 → 그 지원이 가능한지
