# 11. 일반 웹판 (Netlify)

클로드 계정이 없는 부모도 쓸 수 있는 판이에요. 화면과 기능은 claude.ai 판과 같아요.

## 주소와 설정
- 주소: https://beamish-haupia-908919.netlify.app
- Netlify 프로젝트 `beamish-haupia-908919`
  - 배포 브랜치 `stage1-api-extras`, 공개(Public)
- 저장소의 `public/index.html`을 그대로 올려요. 빌드 명령은 없어요(`netlify.toml`).
  - 기관 원본 자료가 저장소에 없어서 Netlify에서는 빌드할 수 없어요.
  - `scripts/build-app.js`가 `app/index.html`(claude.ai 판)과 `public/index.html`을 함께 만들어요.
  - 주간 자동 갱신이 저장소에 올리면 Netlify가 자동으로 새로 배포해요.

## 무엇이 어디에 저장되나
- **각자 기기에만**: 아이 성향 설문, 상담 기록, 메모, 출발지, 비교함
  - 브라우저 기록을 지우면 사라져요. 필요하면 「내 기록」 탭에서 백업 파일로 받아 두면 돼요.
- **운영자에게 자동으로 모이는 것**: 희망 순서(지원할 3곳, 기관 이름과 순서)만
  - 화면 위 저장 줄에 "희망 순서는 서비스 운영 목적으로만 확인됩니다"가 보여요. 누르면 자세한 내용이 나와요.
  - 기기마다 무작위 번호(P-…)와 비밀 토큰을 만들어요. 같은 기기만 자기 기록을 고치거나 지울 수 있어요. 이름·연락처는 받지 않아요.
  - 부모가 희망 순서를 비우거나 「내 기록 모두 지우기」를 하면 서버에서도 지워져요. 2027-03-31에는 자동으로 지워져요.
- claude.ai 판은 따로예요. 계정 저장소의 visible 표로 희망 순서·비교함·조건·추천 설정·출생연도를 운영자가 봐요(docs/08).

  - **내 계정**: 비밀번호 바꾸기, 로그아웃

## 서버 (Supabase `ysdofnaypwxkkkbkgtcm`)
- `supabase/functions/plan`: 희망 순서 받기
  - 검사, 같은 곳에서 1시간 60번까지, 토큰 확인, 빈 목록이면 삭제
  - JWT 확인은 꺼요.
