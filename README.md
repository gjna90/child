## 지금 들어 있는 것

- `src/lib/age.js` — 반 이름 해석('5세반' ≠ 만5세반), 출생연도 → 반, 유아반 보유와 '우리 아이 반 있음' 구분
- `src/lib/fact.js` — 정보 한 칸마다 출처·기준일·확인일·확인 상태·변경 이력 저장, 미확인은 비워 둠, 사용자 기록 보존
- `src/importers/` — 유치원알리미·어린이집 공식 자료 정리: 가정어린이집 제외, 직장어린이집 제한 표시, 폐원 제외, 중복 제거, 출처가 다른 같은 기관 합치기(이름+주소 → 유치원코드), 최신 공시에 없는 기관 표시, 같은 이름의 다른 기관 경고, 지역 판정
- `src/importers/kinder-api-extras.js` — 인증키 API 추가 항목(방과후·교실면적·건물·수업일수·안전점검)
- `scripts/collect.js` — 인증키가 있으면 API 조회, 내려받은 파일(`data/raw/`)도 읽어 명부와 집계 생성
- `test/` — 검증 테스트 30개 (가상 테스트 데이터는 `test/fixtures`에만 있음)

## 사용자가 해 주셔야 할 설정

### ① 이 작업 환경의 인터넷 허용 — 완료 (Full)
유치원알리미·공공데이터포털은 접속됩니다. 어린이집정보공개포털·유보통합포털·아산시·충남교육청은 상대 서버가 해외 접속을 끊어 ③ 방식이 필요합니다.
(참고: 처음 설정 때의 안내)
1. claude.ai/code 화면 위쪽 제목줄의 **환경(클라우드 환경) 메뉴** → **Edit(편집)**
2. **Network access(네트워크 접근)** 에서 **Full** 을 고르거나, **Limited** 상태에서 **Allowed domains** 에 아래 주소 추가 (Allow package managers 체크는 그대로)
   ```
   e-childschoolinfo.moe.go.kr
   info.childcare.go.kr
   api.childcare.go.kr
   www.childcare.go.kr
   enter.childinfo.go.kr
   www.data.go.kr
   apis.data.go.kr
   www.cne.go.kr
   www.asan.go.kr
   ```
3. 안내 문서: https://code.claude.com/docs/en/cloud-environments#network-access

공식 사이트가 해외 접속을 막는 경우도 있어, 허용 후에도 안 되면 ③의 '파일 올리기' 방식으로 진행합니다.

### ② 인증키 받기 — 유치원알리미는 완료 (API = 프로그램이 공식 자료를 자동으로 받아오는 통로, 인증키 = 그 통로의 출입증)
- **유치원알리미**: https://e-childschoolinfo.moe.go.kr → 자료실 → OPEN API → 로그인 후 '유치원 기본현황' 등 신청 (자동승인으로 안내됨)
- **어린이집정보공개포털**: https://info.childcare.go.kr → 보육정보공개 API → 회원가입 → 개발계정 신청 → (승인 후) 운영계정 신청. 개발계정은 한 번에 50건까지만 보여줍니다.
- 받은 키는 채팅에 붙여 넣지 마세요. 환경 설정(제목줄의 환경 메뉴 → Edit)에서 **Network secrets**(없으면 환경 변수)에 이름 `KINDER_API_KEY`로 넣습니다. 새 세션부터 적용됩니다.

### ③ 어린이집 자료: PC에서 받아 올리기 (이 환경에서는 접속 차단)
유치원은 자동으로 받습니다. 어린이집은 한국 PC에서 받아 대화창에 올려 주세요. 파일 이름에 '어린이집'을 넣으면 자동 인식합니다(CSV·JSON·XML).
- 어린이집정보공개포털(info.childcare.go.kr)에서 아산시 어린이집 목록·기본정보를 내려받을 수 있으면 그 파일
- 또는 같은 포털의 Open API 인증키로 아산시(시군구코드 44200) 기본정보를 조회한 결과 화면을 저장한 파일
- 메뉴 위치는 이 환경에서 화면을 열어 볼 수 없어 확인하지 못했습니다. PC 화면을 보며 함께 찾으면 됩니다.
- 참고: 공공데이터포털의 '전국어린이집표준데이터'는 현재 파일 다운로드 없이 API로만 제공됩니다.

## 실행 (설정 후)

```bash
npm test                         # 검증 테스트
npm run collect                  # 공식 자료 수집 → data/roster/<날짜>.json
node scripts/stage1-report.js    # 명부 문서 → docs/03_기관명부_<날짜>.md
npm run notices                  # 유치원 홈페이지 공지·모집요강 수집 → data/notices/<날짜>.json (HWP 읽기에 olefile 필요)
```
